# Chemistry Quest — Challenge Edition

## ชื่อและวัตถุประสงค์ของโครงการ

Chemistry Quest เป็นเกมการเรียนรู้เคมีที่พัฒนาด้วยภาษา Python และเล่นผ่าน Terminal สำหรับโครงงาน Rush00 วิชา Creative Python Application ของ 42 Bangkok

ผู้เล่นรับบทเป็นนักวิทยาศาสตร์ที่ต้องรวบรวมการ์ดธาตุ ตอบคำถามเกี่ยวกับสูตรเคมี และบริหารทรัพยากรที่มีจำกัด เพื่อกู้เครื่องปฏิกรณ์ของห้องทดลองให้สำเร็จ เกมช่วยฝึกการอ่านสูตรเคมี การคำนวณจำนวนอะตอม มวลโมล ร้อยละโดยมวล และจำนวนโปรตอน

การ์ดและปฏิกิริยาในเกมเป็นแบบจำลองเพื่อการเรียนรู้ ไม่ใช่คำแนะนำสำหรับการทดลองเคมีจริง

## สิ่งที่ต้องเตรียม

- Python 3 โดยใช้เวอร์ชันที่ประกาศใน Discovery Piscine
- Terminal ที่รองรับ UTF-8 เพื่อแสดงภาษาไทย สัญลักษณ์ และอีโมจิ
- ไม่ต้องติดตั้งไลบรารีเพิ่มเติม เพราะใช้เฉพาะไลบรารีมาตรฐานของ Python

## วิธีเปิดโปรแกรม

เปิด Terminal ในโฟลเดอร์ `rush/` แล้วใช้คำสั่ง:

```bash
python3 Edited_chemistry_quest.py
```

สำหรับ Windows หากใช้คำสั่งด้านบนไม่ได้ ให้ลอง:

```powershell
py -3 Edited_chemistry_quest.py
```

จากนั้นตั้งชื่อตัวละคร เลือกระดับความยาก 1–3 และเลือกเมนูที่ต้องการ หากไม่กรอกชื่อจะใช้ชื่อ `Scientist` และหากเลือก 0 ในหน้าระดับความยากจะใช้ระดับ Researcher

## วิธีเล่นโดยสรุป

- สำรวจพื้นที่เริ่มต้นเพื่อเก็บการ์ด H, O และ C
- นำการ์ดไปใช้ในห้องทดลอง และตอบคำถามเพื่อค้นพบสูตรเคมี
- รับ XP เพื่อเพิ่มระดับและปลดล็อกพื้นที่ใหม่
- ดูแลพลังชีวิต พลังงาน เสบียง เงิน และความสมบูรณ์ของเครื่องปฏิกรณ์ โดยใช้แคมป์และร้านค้าเมื่อจำเป็น
- ค้นพบสูตรเคมีให้ครบ 6 ชนิด แล้วผ่านด่านบอสเพื่อชนะเกม
- หากความสมบูรณ์ของเครื่องปฏิกรณ์เหลือศูนย์ระหว่างเล่น จะเข้าสู่หน้าแพ้เกม ซึ่งเลือกเริ่มใหม่ โหลดเซฟ หรือออกได้

เกมมีความยาก 3 ระดับ ได้แก่ Explorer (เริ่มต้น), Researcher (ท้าทาย) และ Nightmare (ยากมาก) โดยปรับทรัพยากรเริ่มต้น พลังงานที่ใช้สำรวจ โอกาสเกิดอันตราย การเสื่อมของเครื่องปฏิกรณ์ จำนวนคำถาม และพลังงานที่ฟื้นฟูเมื่อพัก

## การใช้งานสมุดบันทึก

แต่ละบันทึกประกอบด้วย ID ชื่อเรื่อง และเนื้อหา โดยเก็บได้สูงสุด 100 รายการ ชื่อเรื่องต้องมีความยาว 1–50 ตัวอักษร และเนื้อหา 1–500 ตัวอักษร

ค้นหาได้จากทั้งชื่อเรื่องและเนื้อหาโดยไม่แยกตัวพิมพ์ใหญ่–เล็ก หากไม่กรอกคำค้นจะแสดงทุกรายการ การแก้ไขและลบใช้ ID ของบันทึก และต้องยืนยันด้วย `y` ก่อนลบ

## โครงสร้างข้อมูลและการประมวลผล

- ใช้ Dictionary เก็บข้อมูลผู้เล่น กระเป๋าการ์ด สูตรเคมี ระดับความยาก และสถิติ
- ใช้ List เก็บพื้นที่สำรวจ สูตรที่ค้นพบ ชุดคำถาม และรายการบันทึก
- ผู้เล่นเพิ่ม ดู แก้ไข และลบบันทึกหลายรายการได้ โดยข้อมูลคงอยู่ตลอดการเล่นครั้งนั้น
- ประมวลผลข้อมูลด้วยการค้นหาตามเงื่อนไข เรียงสูตรตามชื่อหรือจำนวนอะตอม รวมจำนวนการ์ด และคำนวณการ์ดที่ยังขาด
- แบ่งงานเป็นฟังก์ชัน เช่น รับข้อมูล สำรวจ ตอบคำถาม จัดการบันทึก ซื้อขาย และบันทึกหรือโหลดเกม

## กฎและการตรวจสอบข้อมูล

- สำรวจได้เมื่อพื้นที่ปลดล็อกแล้วและมีพลังงานเพียงพอ
- ทดลองได้เมื่อมีการ์ดและพลังงานครบตามเงื่อนไข
- ซื้อของได้เมื่อมีเงินเพียงพอ และขายการ์ดได้ไม่เกินจำนวนที่มี
- เข้าด่านบอสได้เมื่อค้นพบสูตรครบและมีพลังงานเพียงพอ
- ช่องรับจำนวนเต็มปฏิเสธข้อความ เลขติดลบ และค่าที่อยู่นอกช่วงที่กำหนด
- เมื่อเลือกเมนูผิดหรือระบุ ID บันทึกที่ไม่มี โปรแกรมจะแจ้งเตือน
- ระบบบันทึกและโหลดแจ้งข้อผิดพลาดด้านไฟล์และรูปแบบข้อมูลที่รองรับการตรวจสอบ

## การบันทึกและข้อจำกัดปัจจุบัน

มีไฟล์เซฟหนึ่งชุด การบันทึกครั้งใหม่จะเขียนทับความคืบหน้าเดิม ควรเลือกเมนู 8 ก่อนออกจากเกม

ไม่ควรแก้ไขไฟล์เซฟด้วยตนเอง เพราะโปรแกรมรุ่นปัจจุบันยังตรวจสอบข้อมูลบางช่องไม่ครบ ไฟล์เซฟที่ผิดรูปแบบบางชนิดอาจทำให้เกิดข้อผิดพลาดหลังโหลด

คำถามสารกำหนดปริมาณของ CaCO₃ ในระบบสร้างโจทย์ปัจจุบันระบุเพียงจำนวน Ca และ C ควรเพิ่มเงื่อนไขจำนวน O หรือระบุว่ามี O เพียงพอในโค้ดก่อนส่งงาน

## การตั้งค่าการแสดงผลเพิ่มเติม

- ตั้งตัวแปรสภาพแวดล้อม `CQ_FAST=1` เพื่อปิดเอฟเฟกต์พิมพ์ทีละตัวและการล้างหน้าจอ
- ตั้งตัวแปรสภาพแวดล้อม `NO_COLOR` เพื่อปิดสีและรูปแบบข้อความแบบ ANSI
- เมื่อส่งผลลัพธ์ออกไปยังช่องทางที่ไม่ใช่ Terminal โดยตรง โปรแกรมจะเปิดโหมดเร็วและปิดสีโดยอัตโนมัติ
